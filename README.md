# Grammar Master

関係詞・比較を対象にした、高校英文法のオリジナル練習サイト（98問）。GitHub Pagesで動く静的サイトです。

## 公開方法

1. GitHubで新しいPublicリポジトリを作成する（例：`Grammar_Master`）。
2. `index.html` / `style.css` / `app.js` / `questions.js` をリポジトリのルートへアップロードする。
3. `Settings` → `Pages` → `Build and deployment` → `Deploy from a branch` を選択する。
4. Branchに `main`、フォルダに `/ (root)` を設定し保存。
5. 表示されたURLをSafariで開く。

## 機能

- ダッシュボード・習得判定（2回連続正解）
- 関係代名詞、関係副詞、関係詞の応用、同等・倍数比較、比較級、最上級
- 4択、記述、15分模擬テスト、間違い復習、暗記カード
- ブラウザのlocalStorageに学習履歴保存
- 記録のJSONエクスポート・インポート、リセット

## 注意

- 教科書やプリントの原文を転載せず、同じ文法のオリジナル問題を収録しています。
- 記述問題は模範解答との簡易文字列比較です。正しい別解でも不正解扱いになることがあります。
- Safariのプライベートブラウズやデータ消去で記録が失われる場合があります。必要に応じてバックアップしてください。
